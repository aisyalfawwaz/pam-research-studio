# Actual j-Wave 64-channel fixture

Generated by `uv run python scripts/make-jwave-reference.py` with app/engine 0.3.0, real unmodified j-Wave 0.2.1, JAX 0.4.38 CPU, float64, Windows 11. 64 receivers, 4096 samples at 20 MHz, source (0,30) mm, 1 MHz Gaussian pulse, 4 µs duration, emission centre 8 µs, SNR 30 dB/seed 42. Propagation spacing 0.2 mm, CFL ceiling 0.3, PML 20, density 1000 kg/m³. Five 128² reconstructed maps.

`bundle/` contains raw RF, maps, full options, actual grid/time mapping, package versions, runner/runtime-lock checksums, metrics, figures, citations and inventory hashes. `experiment.zip` is the same portable package; `BENCHMARK.json` records the observed run. Envelope arrival error against nominal distance/c was at most 0.05 µs. This is 2D line-source physics, not a calibrated 3D point-source experiment.

```powershell
uv run python -m pamstudio.cli reproduce examples/jwave_64ch/bundle
```

Install the optional runtime with `scripts/setup-jwave.ps1` first. Import the ZIP using File → Import experiment in an open project. Results remain experimental; inspect broad axial response and high background ratios in the measurements. See `adapters/jwave/README.md` for limitations.
