# Three-source localization fixture

Generated by `uv run python scripts/multipeak-evidence.py`. Every map comes from the same actual simulated RF. `evidence.json` records the immutable run, local project, settings and file hashes. Original example folders remain unchanged.

Import `experiment.zip` through File → Import experiment, select **ATP**, and set peak threshold **−12 dB**, minimum separation **2 mm**, truth matching tolerance **2 mm**. Three independent peaks match S1, S2 and S3. Open Source localization for coordinates and errors, then Benchmark for method comparisons.

`selected.json/.csv` use those settings. `sensitive.json/.csv` lower the threshold to −20 dB and retain two extra ATP peaks. `strict_match.json/.csv` use 0.05 mm matching tolerance: all three ATP peaks stay at the same coordinates, but two fail the tighter gate. `localization.pdf` contains annotated maps and per-source matching tables; the companion `.report.json` retains complete peak lists and hashes. The ZIP's built-in benchmark uses documented detector defaults (−20 dB, 1 mm separation, 2 mm matching tolerance); select the settings above for the selected report.

From the repository root, run `uv run python -m pamstudio.cli reproduce examples/multiple_sources/experiment_files_8ac778cf` to reproduce DAS, TEA, CF and ATP maps. Detector definitions and limitations are in `docs/PEAK_DETECTION.md`.
