# Frozen 0.10 research evidence

Generated by `uv run python scripts/research-evidence.py` using synthetic sources only. Existing examples were preserved. `evidence.json` records hashes, project location, study IDs and selected run IDs. Each PDF has a full `.report.json` context and checksum; CSV/JSON retain all case outcomes.

- Sweep: 2 SNR × 2 source-position cases; DAS, TEA and CF.
- Convergence: grids 33, 49 and 65 on identical noise-free RF; sampled relative L2 errors.
- Uncertainty: 16 seeded trials, 15 m/s host-speed SD and 40 µm independent element-coordinate SD; nominal receive calibration, actual capture errors and 30 dB RF noise.
- Population: real coupled jbubble → separate causal volume flows → j-Wave → 16-channel RF → three PAM maps. Source 1: 2 µm lipid bubble, 20 kPa; source 2: 1.5 µm free bubble, 15 kPa; different source positions and ringdown. This is independent one-way coupling, not interacting bubbles.
- Synthetic CT: the native test's saved skull-phantom RF reconstructed with homogeneous and CT straight-ray delays. `ct-comparison.json` records the actual paired scores and exact RF equality; `ct-corrected-experiment.zip` preserves the corrected run and HU asset. Improvements are not assumed for every score.

`population-experiment.zip` and `uncertainty-experiment.zip` include raw RF, maps, original scientific provenance, references and hashes. Their companion folders are executable with `uv run python -m pamstudio.cli reproduce <folder>`. Import a ZIP through File → Import experiment. Study histories remain in the local project listed in `evidence.json`; standalone study JSON/PDF exports are reports, not imports into a new journal.

`bubble.webm` and `pipeline.webm` are actual 6-second, 960 × 640, 20 fps exports from the coupled population (120 timestamped VP8 frames each), with selected source 2, native playback/seek verification and SHA-256 context companions. They use saved numerical data; physical time is resampled into slow motion. Source credit and the encoding implementation are recorded in `.webm.json`.

Bootstrap intervals describe this assumed simulation error model. The results are implementation fixtures, not independent method validation or clinical calibration. Population and uncertainty metrics can legitimately be unavailable when truth masks, width crossings or sufficient nondegenerate data are absent.
