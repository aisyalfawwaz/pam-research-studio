# Dependency provenance and attribution

Review date: 2026-11-11. Original project code has no selected redistribution license pending owner/institutional decision. Optional j-Wave and jbubble packages are now installed unmodified in isolated environments. No third-party scientific source is vendored or translated into the repository. Dependencies retain their licenses and authorship.

## Optional installed research libraries

Research report export adds **ReportLab 5.1.0**, BSD-3-Clause, copyright ReportLab Inc.; authors Andy Robinson, Robin Becker, the ReportLab team and community. Its installed `reportlab-5.1.0.dist-info/licenses/LICENSE` and collected notices are authoritative. The new transitive **charset-normalizer 3.5.2** dependency is MIT. Both installed Python licenses are included by `scripts/license-inventory.py`.

Timestamped WebM export uses **Mediabunny 1.65.2**, by Vanilagy (David P.) and contributors, **MPL-2.0**, unmodified. Its original full license is retained in `docs/MEDIABUNNY_LICENSE.txt`; exact upstream source and integrity are in `docs/MEDIABUNNY_SOURCE.json` and `pnpm-lock.yaml`. Obtain corresponding source from [the pinned original npm archive](https://registry.npmjs.org/mediabunny/-/mediabunny-1.65.2.tgz) or the installed package's `src/` directory. MPL-covered source modifications would need publication under MPL-2.0; no upstream source is modified here. The transitive `@types/dom-webcodecs` and `@types/dom-mediacapture-transform` packages retain MIT notices in their installed distributions. Chromium WebCodecs supplies VP8 encoding; no FFmpeg executable is installed or redistributed. A packaged release must include these notices and source-access instructions.

Each `adapters/<name>/uv.lock` retains package hashes. Installed inventories are in `adapters/<name>/dependencies.json`; collected notices are in `docs/JWAVE_THIRD_PARTY_NOTICES.txt` and `docs/JBUBBLE_THIRD_PARTY_NOTICES.txt`. Rebuild them using the respective optional interpreter and `scripts/adapter-inventory.py jwave` / `jbubble`. GPL/LGPL native redistribution obligations require a release audit; no binary bundling or installer is delivered. Upstream license/citation URLs and platform limitations are documented in each adapter README. Local CPU tests are implementation evidence, not upstream Windows support or institutional endorsement.

## Public anatomy dataset

One metadata-minimized axial head CTA instance is included under **CC BY 4.0**, from Evgenia Blagosklonova, Daria Dolotova, Natalia Polunina, Elena Grigorieva, Denis Pakhomov, Vladimir Krylov and Andrey Gavrilov, [Zenodo DOI 10.5281/zenodo.15697196](https://zenodo.org/records/15697196). Full attribution and modifications are in `datasets/open_head_ct/ATTRIBUTION.md` and `SOURCE.json`; unchanged pixel values, decompression and rebuilt identifiers/local origin are documented. Dataset licensing is separate from application code. Exports preserve the authors, source, license, modifications and hashes. Automated tests use synthetic inputs only.
